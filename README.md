# PyTorch Practice

A collection of PyTorch projects built to develop practical deep learning skills, with an emphasis on writing custom models and training loops rather than relying on high-level APIs.

## Projects

### [Brain Tumor MRI Classification](./MRI_Tumor_Detection)
A CNN that classifies brain tumor type (glioma, meningioma, pituitary, or no tumor) from MRI scans.

### [Visual Stimulus Decoding from Calcium Imaging](./Stimulus_Decoder)
A GRU-based RNN that decodes visual grating orientation from mouse visual cortex calcium imaging data (Allen Institute Visual Coding dataset), achieving 37.5% accuracy vs. 12.5% chance.

### [DNA Methylation Predictor](./DNA_Methylation_Predictor)
A feedforward neural network that predicts DNA methylation status from biological features, demonstrating deep learning applications to epigenetic classification using tabular genomic data.
